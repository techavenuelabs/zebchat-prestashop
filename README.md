# ZebChat live chat for PrestaShop

Add the [ZebChat](https://www.zebchat.com) live chat widget to your PrestaShop shop. Sign in (or
create a free account) from the back office, pick your shop and turn the chat on. No code to
paste. The widget prints in the shop footer.

- PrestaShop 1.7.7 through 9
- License: GPL-2.0-or-later

## Install

1. Download `zebchat-prestashop.zip` from the
   [latest release](https://github.com/techavenuelabs/zebchat-prestashop/releases/latest).
   Use that file, not GitHub's "Source code" zip: PrestaShop needs the folder inside the zip to
   be named `zebchat`.
2. Back office: **Modules → Module Manager → Upload a module**, and drop the zip.
3. Click **Configure** on ZebChat.

## Set up

1. Sign in to ZebChat or create an account.
2. Pick this shop's website and turn the chat on.
